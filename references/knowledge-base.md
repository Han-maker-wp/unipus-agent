# 知识库检索（knowledge-base）

## 结构

```
knowledge/
├── INDEX.md                    # 全量书目（21系列/约200本），转录状态在每行「转录状态」列
└── <系列名>/<教材名>.md          # 一本书一个文件，按 Unit → 小节 组织
```

单书文件内格式（也是新转录必须遵守的格式）：

```markdown
# <教材名>— Unit N <单元主题>
> 已转录单元：…

## Reading 1 · 1-2 Get ready to read · Listening for information
1. 答案…
2. 答案…

## 1-6 Read and practice · Banked cloze
词库：adequate / assigned / …
1. finals
2. due
```

**小节标题必须与 U校园页面显示的小节名逐字一致**（如 `1-6 Read and practice · Banked cloze`），
这是检索命中率的根基。

## 检索流程

1. 确定教材：课程页教程名 ↔ INDEX.md 书名（U校园「新编大学英语（第四版）综合教程 3（2023版）」
   ↔ 知识库「新编大学英语 综合教程3」，版本词 2023版/第四版/智慧版要对上）。
2. 打开对应书文件，按当前 Unit 与小节名定位章节（AI 直接读文件，或 grep 小节名）。
3. 题目级匹配：
   - **Banked cloze**：先比对词库（词集一致才可信），再按题号取答案。
   - **选择/判断**：按题干关键词（去停用词后 2-3 个实词）在小节内搜。
   - **填空**：用空格前后 3-5 个词做上下文匹配。
   - **翻译/写作**：按小节名对号入座，全文取用。
4. 命中置信度：词库+题号双匹配=高；仅题干关键词=中；只有小节名=低（需 AI 自己复核）。

## 检索命令示例

```bash
grep -n "Banked cloze" "knowledge/新编大学英语（第四版）/新编大学英语 综合教程3.md"
grep -n -A 12 "1-6 Read and practice" "knowledge/新编大学英语（第四版）/新编大学英语 综合教程3.md"
```

## 知识库未覆盖时

- 书存在但该 Unit 未转录（状态 ⏳）：按 references/kb-builder.md 现场补录该单元（约 10-20 分钟），
  或告知用户后 AI 直接作答（全部标低置信度，提交策略自动降级为「只填不交」）。
- 书不存在（❌/无此书）：AI 作答 + 明确告知用户无答案源可比对。

## 版本校验

U校园课程页 hash 里的教材代码（如 `nce_4_rw_3`）与知识库书名对应关系：

| 代码片段 | 教材 |
| --- | --- |
| nce_4_rw_N | 新编大学英语（第四版）综合教程 N |
| nce_4_lsn_N（示例，以实测为准） | 新编大学英语（第四版）视听说教程 N |

首次遇到新代码时，打开教程详情页核对教材全称，并把映射补进本表。
