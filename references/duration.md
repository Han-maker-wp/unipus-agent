# 学习时长挂机（duration）

> 目的：U校园后台记录学习时长。AI 作答只需几十秒，「秒完成」在时长统计上很扎眼，
> 所以每节任务配置一个最短停留时间，剩余时间在页面上挂机。

## 配置

- `每节时长`：默认 **10 分钟**/节（用户可指定，会话开始时确认一次）。
- 作答+核查耗时通常 1-3 分钟，剩余全部用于挂机。

## 挂机流程

1. 回填+核验完成后，明确告知用户：
   「本节已完成，剩余 N 分钟将在页面挂机积累学习时长（**正常现象，不是卡死**），期间你可以随时接手。」
2. 挂机动作（拟人）：
   - 每 60-120 秒一次轻量滚动（页面滚动 200-400px，到底再滚回）；
   - 每 3-5 分钟移动一次鼠标位置（坐标 hover 无点击）；
   - 绝不点击「提 交」及任何会改变作答状态的控件。
3. **每分钟输出一次心跳**（红线 8）：
   `⏳ [教材 Unit N·小节] 剩余 M 分钟 · 正常挂机刷时长，非故障`
4. 倒计时结束才离开页面进下一节；离开前重跑一次 extract_questions 确认答案仍在（被平台清空则按
   submit-policy 处理并记录异常）。

## 节奏参考

| 阶段 | 建议耗时 |
| --- | --- |
| 进入任务+关弹窗 | 5-10s（自然加载） |
| 提取+检索+审核单 | 30-90s |
| 回填+核验 | 30-60s |
| 挂机 | 补足到每节配置时长 |

## 多节连做

一节结束 → 回目录（确认状态变化）→ 下一节。整单元做完输出汇总。
连续工作每 30-40 分钟主动休息 1-3 分钟（只挂机不作答），更接近真实学习节奏。
