## 每本书的标准流水线（照 kb-builder.md）

1. IAB 浏览器抓书籍文章 → 提取单元文章链接 → `tools/manifests/<书>-units.json`
2. 逐单元抓文章 data-src 图链 → `.cache/<书>-unit-images.json`
3. `python tools/download_images.py` 下载截图
4. 视觉转录 ≤5 张/批 → 单元稿 → 拼装 `knowledge/<系列>/<书>.md`
5. `python tools/verify_kb.py --book <关键词>` 全绿
6. 删 `.cache/images` 对应目录 → INDEX.md + 本文件状态更新 → commit + push

## 无视觉能力时的 OCR 转录法（2026-09-28 视听说3 实测）

主模型与子代理均不支持图像输入时（Read 图片返回 "Media omitted ... does not support image input"），改用 RapidOCR（PP-OCRv4 中英，CPU）流水线，脚本在 `.cache/`：

- `ocrall.py <image_dir> <out_dir> <screen>...` — 逐屏 OCR，输出带坐标/红字标记的文本
- `show.py <out_dir> <screen>...` — 精简查看（滤水印、滤 blob 列表）
- `cropall.py <dir> <screen> x0 y0 x1 y1 [zoom]` — 局部放大重识别
- `redocr.py <dir> <screen> x0 y0 x1 y1 [zoom]` — **红笔隔离**：只保留红像素→黑字白底→放大，捞手写红笔答案

关键经验：

1. **答案红 vs 水印红要按通道分开**：答案红是饱和 `(192,0,0)`（g/b 近 0），水印红是浅 `(237,153,152)`（g/b 近 150）。用 `r>90 & g<100 & b<100` 可干净滤掉「公众号·满分学习」斜向水印。
2. **红笔选择题答案的定位法**：红笔勾会压住选项字母，导致该行 OCR 失败或字母误读（B→R、C→Q/O、D→F），不能靠"哪一行被标记"判断。正确做法是取红笔 blob 的**像素范围**（x≈66-82），按 y 排序与选项行做**位置索引**，误读字母统一归一化为 A/B/C/D。
3. 水印残片会产生大量 1px 宽的假 blob，判定真答案要设 `宽度>=3 且 像素数>=60` 双阈值。
4. **OCR 转录无视觉核验**，Scripts 原文可能有字符级误差，作答时以音频/题干为准；建议在有视觉能力的会话抽查带答案的屏。

## 微信反爬要点（2026-09-27 实测）

- mp.weixin.qq.com 对本机 IP 有 wappoc 概率性挑战；browser-use IAB 持久 profile 的白名单 cookie 有效，同一 URL 重试 2-5 次（间隔 2.5-4s）即通过，无需人工滑块
- poc 重定向会让 goto 抛 ERR_ABORTED，须 try/catch
- 单本书 8 单元×~20 图约 160 张，转录约一个会话的量
